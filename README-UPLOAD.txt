GITHUB PAGES UPLOAD INSTRUCTIONS

1. Unzip this file on your computer.
2. Upload BOTH of these to the root of your GitHub repository:
   - index.html
   - assets folder
3. Do not upload the ZIP file directly.
4. Do not upload only index.html, because images need the assets/images folder.
5. In GitHub Pages settings, publish from the branch root folder.

This v3 version has:
- No loader overlay
- No hidden reveal animation
- No JavaScript dependency
- No external fonts
- Simple relative image paths: ./assets/images/filename.jpg
- Full footer included
